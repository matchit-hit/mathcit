MATCHIT V1 — TIINY HOST TEST BUILD

WHAT THIS IS
A responsive MATCHIT storefront prototype with a local demo admin panel.
It includes product add/edit/delete/duplicate, categories, option rows, image upload,
cart, checkout, discount-code UI, order preview, theme toggle and responsive animations.

IMPORTANT LIMITATION
This ZIP is a FRONT-END DEMO. It uses browser localStorage.
Admin changes, uploaded images, demo login, cart and orders are saved only in the
browser/device that made them. They do NOT sync to other visitors or devices.
The demo login is NOT secure and must not be used for a real public store.
Do not enter real customer details or sensitive information into this demo.

For the full production MATCHIT system (one admin, secure login, shared database,
server-side image storage, globally visible product changes and central orders),
connect an external backend/database and image storage service. Tiiny Host itself
does not provide a database. Do not publish this demo as a live shop for real orders.

DEPLOY TO TIINY HOST
1. Keep index.html at the root of the ZIP (it is already there).
2. Upload MATCHIT_V1_Tiiny_Test.zip to https://tiiny.host
3. Publish it as a test project.
4. Open the published link and browse the pages.
5. Open /control-center.html to try the demo admin.
6. Create a demo username and password in that browser.
7. Add/edit/delete products and test the storefront.

LOCAL TEST
Extract the ZIP, then double-click index.html.
For best results, use a modern browser.

PRODUCT IMAGE UPLOAD
Use Control Center > Products > Edit/Add Product > Upload product images.
The Media Library also accepts image uploads. In this demo images are stored in
the browser's local storage, not uploaded to Tiiny Host's server.

WHATSAPP / INSTAGRAM
Open Control Center > Store Settings and add your shop's WhatsApp number and
Instagram profile URL. WhatsApp checkout sharing is enabled after a number is set.
Instagram DM routing needs a configured profile link and manual follow-up.

This is a test build, not a production commerce backend.
